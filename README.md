# Classic AI TV Preview

Classic AI TV Preview is a personal, non-commercial Android TV home-screen prototype. It is being developed for use on one privately owned television. It is not sold, monetized, or distributed as a streaming service.

The interface has a six-app dock controlled by a TV remote, an expandable list of installed apps, a clock and compact weather panel, and a film backdrop carousel. The app opens installed streaming apps; it does not host or stream films itself.

## TMDB use

The planned film carousel requests the TMDB top-rated movie list and wide backdrop images. It shows a film's title, year, and TMDB rating. Selecting a film opens its TMDB information page; playback is not provided by this app. The API credential is entered by the owner in the app's settings and is not included in the APK or this page.

The project is an Android TV prototype currently being tested locally. The TMDB feature is prepared but has not yet been tested on the television with an API credential. There is no public download at this time.

Data and images: [The Movie Database (TMDB)](https://www.themoviedb.org/).

This product uses the TMDB API but is not endorsed or certified by TMDB.

## Privacy and scope

The carousel sends requests to `api.themoviedb.org` and `image.tmdb.org` when enabled and configured. It does not send a home address, TV serial number, or account password to TMDB. The API credential should be kept private.

This page describes the owner's personal prototype. It does not contain the television's recovery files, personal photos, APK signing material, or any API credentials.
